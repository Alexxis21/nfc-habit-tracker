# NFC Habit Tracker - System Budowania Nawyków NFC

Aplikacja mobilna i system backendowy wspierający budowanie nawyków za pomocą zbliżeniowych naklejek NFC.

## 📁 Struktura Projektu

- [`/backend`](file:///Users/aleksandraswiderek/Desktop/nfc-habit-tracker/backend) - Serwis backendowy (Spring Boot 3, Java 21, PostgreSQL, Flyway)
- [`/mobile`](file:///Users/aleksandraswiderek/Desktop/nfc-habit-tracker/mobile) - Aplikacja mobilna (React Native / TypeScript)
- [`/docs`](file:///Users/aleksandraswiderek/Desktop/nfc-habit-tracker/docs) - Dokumentacja techniczna, diagramy ERD oraz reguły biznesowe

## 🛠️ Stos Technologiczny

- **Aplikacja Mobilna:** React Native, TypeScript, React Query, Axios, Native NFC
- **Backend:** Java 21, Spring Boot 3, Spring Security (JWT), Hibernate / JPA, Flyway
- **Baza Danych:** PostgreSQL 16
- **Konteneryzacja:** Docker & Docker Compose
- **Sprzęt:** Tagi NFC NTAG215 (NFC Forum Type 2)
